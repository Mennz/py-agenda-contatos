# Agenda de contatos em Python

Agenda de console que adiciona, lista, busca e remove contatos. Os dados ficam
salvos em `contatos.json`, que e criado automaticamente na primeira execucao.

## O que pratiquei

- Separar as funcoes da agenda (`agenda.py`) do menu (`main.py`)
- Manipular uma lista de dicionarios como estrutura de dados
- Ler e escrever JSON com o modulo `json`
- Busca por nome com correspondencia parcial (usando `in`)
- Validacao simples de entrada

## Como rodar

```
python main.py
```

Digite o numero da opcao desejada no menu. Pra sair, escolha a opcao 5.
